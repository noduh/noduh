## Favorite Projects

### [TUI Snake](https://github.com/noduh/TUI-Snake)

The classic game Snake, cloned to be played in the terminal. I used this as a project to learn basics of programming in Kotlin. It's a game I like to play, and it seemed like a project that fits the scope of learning a new language.

- Adapts to fit the size of the terminal when run
- Listens to key press events
- Used Kotlin with Gradle
- Implemented 3rd party library "kotter" by varabyte
- Runs locally in a terminal
